# Archive Directory

## Purpose
Long-term retention of superseded documentation, legacy backups, and deferred enhancement plans.

## Structure
- `backups/`: Pre-alpha backup artifacts with integrity checksums.
- `legacy_notes/`: Historical notes superseded by CONTEXT_SNAPSHOT.md, VISION.md, and structured docs/.
  - `README_LEGACY.md`, `INSTALL_LEGACY.md`, `PATCH_NOTES_LEGACY.md`: Original root-level docs (consolidated into docs/)
  - `PRE_ALPHA_NOTES.md`, `ADAPTATION_BRAINSTORM.md`, `STEP_6_CRASH_DETECTION.md`, `TESTING_CHECKLIST.md`: Development notes
- `demos/`: Early demonstration scripts now replaced by formal workflows.
- `enhancement_plans/`: Future feature designs (Phase 8+ scope).

## Retention Policy
- Artifacts retained indefinitely until Phase 4 size-based pruning policy defined.
- Checksums preserved for all binary archives.

## Retrieval
Files moved here are queryable via git history. Restoration: copy back to root or docs/ as needed.
